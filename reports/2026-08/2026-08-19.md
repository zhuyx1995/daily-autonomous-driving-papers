## 1. Geometry-Aware Spatio-Temporal Context Modeling for 4D Occupancy Forecasting

- arXiv： [arXiv:2608.15279](https://arxiv.org/abs/2608.15279)
- 首次提交：2026-08-15

**研究问题**
- 4D occupancy forecasting 要同时预测未来 3D 场景的几何占据和时序演化，是自动驾驶感知-预测链路里很关键的基础模块，尤其影响 corner case 仿真、长期场景推演和下游规划的世界状态建模。
- 现有方法常用离散 token + 自回归预测，但很容易在静态结构上引入几何畸变，也容易在长时间预测时丢掉时序一致性，导致未来占据既不“稳”也不“真”。

**核心方法总结**
- 论文提出 **GAST (Geometry-Aware Spatio-Temporal context modeling)**，核心是把 4D occupancy forecasting 拆成“几何保真生成 + 时空一致性建模”两个耦合阶段。
- 在生成侧，作者用 pose-driven warping、motion-aware feature modulation 和 attention-based feature refinement，先逐帧生成几何更稳定、语义更合理的 occupancy。
- 在时空建模侧，方法再通过 global context aggregation 强化空间一致性，并通过 temporal dynamics extraction 捕捉场景随时间的演化，把历史重建与未来预测放进同一个端到端框架里联合优化。
- 摘要结果显示，它在 **Occ3D-nuScenes** 上相对此前 SOTA 带来 **mIoU +7.67%、IoU +6.44%**，同时还有 **2.84×** 的速度提升，说明这不是单纯精度换算力的方案。

**一句话摘要**

## 2. Risk-Adaptive Edge--Cloud Visual Reasoning for Communication-Efficient Autonomous Driving

- arXiv： [arXiv:2608.14991](https://arxiv.org/abs/2608.14991)
- 首次提交：2026-08-15

**研究问题**
- 大模型视觉推理对自动驾驶的上下文理解有帮助，但如果把图像频繁上传到云端做 VLM 推理，会直接引入通信开销、网络延迟和决策时延，这在车端战术决策里很难忽略。
- 真正落地的关键不是“要不要云端推理”，而是 **什么时候值得请求云端**，以及怎样保证验证、控制和 AEB 这类安全关键环节仍然留在本地闭环里。

**核心方法总结**
- 论文提出一个 **risk-adaptive edge-cloud** 架构：由车端先做交通态势评估，只在风险和语义事件达到阈值时，才触发云端视觉语言推理。
- 车端部分由 onboard VLM + lightweight detector 负责抓取时间上下文和相对路径风险，用于保守本地响应与选择性云请求；云端模型提供更强的战术建议，但 **validation、vehicle control 和 automatic emergency braking 仍保持本地执行**。
- 这个设计本质上是在“云端高能力推理”和“车端低时延安全闭环”之间做风险自适应分工，而不是把整个驾驶决策一股脑丢到云上。
- 摘要结果显示，在 **CARLA** 中，它在维持与周期性云访问相当任务成功率的同时，把云请求数减少 **54.1%**，并减少了 AEB 触发；在延迟道路施工的消融实验里，也能比固定周期审计更早触发云请求。

**一句话摘要**
